# Weather & Climate Big Data Analytics Project

A big data analytics and machine learning project using the [Open-Meteo API](https://open-meteo.com/) for weather and climate clustering.

## Project Structure

```
weather-clustering/
├── data/           # Raw and processed datasets
├── src/            # Core source code (API fetching, processing, clustering models)
├── notebooks/      # Jupyter notebooks for data analysis & exploration
├── dashboard/      # Web visualization / dashboard application
├── tests/          # Unit and integration tests
├── docs/           # Documentation and report assets
├── README.md       # Project overview
├── requirements.txt# Project dependencies
└── .gitignore      # Git ignore configuration
```
