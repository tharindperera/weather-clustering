# Location Catalogue

## Source

SimpleMaps Basic World Cities Database.

License: Creative Commons Attribution 4.0 (CC BY 4.0).

## Selection

A deterministic selection procedure was applied to obtain
100 geographically diverse cities from the source database.

Selection included:

- valid city and country identifiers
- valid latitude/longitude
- preference for locations with known population
- one representative record per city-country identity
- global geographic coverage

## Final dataset

- Locations: 100
- Countries represented: 80

## Columns

| Column | Description |
|---|---|
| location_id | Stable SimpleMaps location identifier |
| city | City name |
| city_ascii | ASCII-normalized city name |
| country | Country name |
| iso2 | ISO 2-letter country code |
| iso3 | ISO 3-letter country code |
| admin_name | Administrative region |
| capital | Capital classification where available |
| latitude | Geographic latitude |
| longitude | Geographic longitude |
| population | Source population estimate |
